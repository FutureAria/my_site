# Career Target Prep

Last updated: 2026-06-04 KST

## Conclusion

박주영 포트폴리오는 `웹/앱 서비스 개발 + 백엔드/API/DB + AI 활용 기능 구현` 방향으로 설명하는 것이 가장 자연스럽다.

지원 직무명은 아래 순서가 좋다.

1. 백엔드 개발자
2. 웹/앱 서비스 개발자
3. 풀스택 주니어 개발자
4. AI 서비스/AI API 활용 개발자
5. SaaS/플랫폼 개발자

순수 ML Researcher, AI 모델 학습 연구원, 시니어 AI 인프라 엔지니어 포지션은 현재 포트폴리오와 바로 맞는 1순위는 아니다. 다만 AI 기능을 서비스에 붙이는 회사, AI SaaS, B2B SaaS, 커뮤니케이션/HR/교육/핀테크 서비스 회사와는 연결 가능성이 있다.

## Portfolio Positioning

현재 사이트 첫 화면은 `AI-assisted · Backend Problem Solver`, `API, DB, 배포 흐름을 직접 구현하고 검증 기록으로 설명합니다.` 방향이다.

면담에서는 아래처럼 말하면 좋다.

> 저는 웹/앱 서비스를 직접 만들고, 백엔드 API와 DB 흐름을 설계하면서 AI나 외부 API를 서비스 기능으로 연결하는 쪽에 관심이 있습니다. 단순히 화면만 만드는 것보다 데이터가 어떻게 들어오고, 저장되고, API로 전달되고, 운영 환경에서 어떻게 검증되는지까지 보는 개발자가 되고 싶습니다.

## Main Project Talking Points

### BASE CHAIN

- 웹/앱 서비스 제작 역량을 보여주는 대표 프로젝트.
- React, TypeScript, Node.js, Express, MariaDB, Oracle 배포 흐름을 말하기 좋다.
- Toss Payments는 실제 결제가 아니라 MOCK/test 결제 흐름이라고 명확히 말해야 한다.
- 강조 문장:
  - `흩어진 버전의 코드를 통합하고, 예매-결제-MOCK 승인-QR 입장 흐름을 운영 데모 형태로 정리했습니다.`

### KIS AI Trader

- AI/데이터/자동화 관심을 보여주는 개인 프로젝트.
- 실제 주문은 잠금, 공개 화면은 읽기 전용이라고 명확히 말해야 한다.
- 강조 문장:
  - `AI 판단 결과를 그냥 실행하는 것이 아니라, 시장 데이터 수집, 판단 근거 표시, 로그 기록, 실제 주문 권한 분리를 중요하게 봤습니다.`

### MajorLink

- 기획형/진행 중 프로젝트로 MVP 범위 정의 역량을 보여준다.
- 완성 기능처럼 과장하지 말고 `MVP 검증 중`으로 말해야 한다.
- 강조 문장:
  - `아이디어를 바로 크게 구현하기보다 프로필, 모집글, 지원/승인 흐름으로 1차 범위를 좁히고 제외 기능을 정리했습니다.`

### AI Music / Commercial District

- AI API와 데이터 기반 추천 흐름을 보조 근거로 쓰기 좋다.
- 강조 문장:
  - `AI 응답을 그대로 화면에 붙이는 것보다, 서비스에서 쓸 수 있는 데이터 형태로 정규화하는 부분에 관심이 있습니다.`

## Interview / Counseling Script

짧게 말해야 하면:

> 저는 웹사이트나 앱처럼 사용자가 직접 쓰는 서비스를 만들고 싶고, 그 안에서 AI나 외부 API를 실제 기능으로 연결하는 회사에 관심이 있습니다. 제 포트폴리오는 BASE CHAIN처럼 웹 서비스 흐름을 끝까지 만든 프로젝트, KIS AI Trader처럼 데이터와 AI 판단 근거를 다룬 개인 프로젝트, MajorLink처럼 MVP 범위를 정리한 프로젝트를 중심으로 구성했습니다. 그래서 백엔드 개발자, 웹/앱 서비스 개발자, 풀스택 주니어, AI 서비스 개발자 포지션을 우선으로 보고 싶습니다.

조금 더 구체적으로 말하면:

> 회사는 서울권 웹/앱 서비스 회사, AI 기능을 제품에 붙이는 스타트업, B2B SaaS, HRTech, 핀테크/데이터 서비스 쪽을 보고 싶습니다. 유명 기업으로는 Toss, Kakao, Naver, Coupang, Woowa 같은 플랫폼 회사도 관심이 있고, 제 방향과 더 직접적으로 맞는 곳은 Upstage, Liner, Wrtn, Sendbird, Channel Corporation, WantedLab, Lablup, FriendliAI 같은 AI/SaaS 계열이라고 생각합니다.
